# Initial roadmap

All items are planned. Use the full project report for detailed targets and evaluation methods.

1. Agree on shared content schema, identifiers, revisions and adapter boundaries.
2. Person 1: build an extraction baseline with legally usable examples and review flags.
3. Person 3: implement private storage, authorization, upload/status/content APIs and durable extraction jobs.
4. Person 2: build accessible navigation and source-page interactions using versioned content.
5. Integrate corrections, conflict handling and dependent-artifact invalidation/rebuilds.
6. Integrate speech, sentence focus and explicit offline chapter downloads.
7. Add chapter-scoped retrieval, evidence responses and optional generated explanations with abstention.
8. Evaluate extraction, accessibility, authorization, revision consistency, job recovery and grounding; document limitations and prepare the demonstration.

## Person 3 first milestone

Start on `person-3`: define contracts with teammates, establish backend configuration, then deliver an authorized upload-to-content pipeline. Add grounded AI after evidence, revisions and authorization are dependable.
